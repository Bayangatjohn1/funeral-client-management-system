# More Actions and feedback corrections

The shared More Actions owner now opens its existing dropdown as a manual popover in the browser top layer. Forms remain in the original row/card DOM so Service's delegated archive/availability submit handler retains its record context. Inline fixed positioning resets all insets and margin, clamps the menu to the viewport, and flips above the trigger when appropriate. This escapes clipped table scrollers and transformed ancestors without moving forms to body.

Menu-item clicks defer menu closure until the next task, allowing submit-button default activation to finish before its ancestor is hidden. This addresses archive buttons that could lose activation when the document click handler synchronously hid the menu. Existing confirmation, dependency blockers, archive routes and requestSubmit flow remain.

Scrolling the page, table or other outer container closes all menus; scrolling inside the menu itself keeps it open. Resize, Escape, outside click and panel reset also close the menu and clear its placement. The initialization remains guarded once per document. Menu colors are #D5E4D9 light / #304C3B dark, with #C1D8CA / #3C5B47 item hover, transparent border and no shadow. A shared late Blade partial covers all panel More Actions consumers, including Service, Branch, User, Case and other existing row menus.

Branch status feedback now uses the same flat centered composition as User/Service feedback: 24px shell padding, 14px body separation, 20px action separation, with compact narrow-screen spacing. Its previous tinted header band is removed only in feedback mode. Confirm buttons across the existing feedback dialogs use amber warning, green success/restore, red error/destructive and neutral Cancel/Close; Branch case-review links use informational blue. The semantic feedback rules override the ordinary sage primary-button skin. Service detail Restore/Available actions now receive the success tone; blocked actions remain errors. No data, policy, route or form-submission semantics change.

Owners: `resources/js/app.js`, `resources/views/partials/record_action_menu_styles.blade.php`, its panel-layout include, `resources/views/partials/record_modal_surface_styles.blade.php`, and Service detail status-tone selection.
