## Additional verified corrections

- **High — intake authorization:** `StaffMiddleware.php` previously allowed admin main/alias intake POSTs despite Staff-only GET/policy intent. The narrower other-branch System Admin exception remains; explicit denial tests now cover all three branches.
- **High — payment retries:** added optional UUID submission identity plus canonical request hash and unique `(branch_id, submission_id)` in `database/migrations/2026_10_21_140000_add_payment_submission_identity.php`. `PaymentController.php` checks retries before overpayment rejection and inside the case transaction lock. The same payload reuses its acknowledged record; changed details under the same identity fail validation. Separate identities permit legitimate equal amount/date payments. The form generates an identity; legacy requests without one remain compatible and cannot be inferred duplicates. `Payment.php` allows these fields. Payment correction replacements clear identity/hash in `PaymentCorrectionController.php`, retaining the original audit trail. `FuneralCase.php` shares paid/balance/status derivation between posting and recalculation.
- **High — MariaDB schema repair:** the April migration attempted to remove a unique client/branch index before providing its FK backing replacement, swallowed failure, and left uniqueness active. `SHOW CREATE TABLE` on isolated MariaDB confirmed it. `2026_10_21_150000_finish_deceased_client_index_repair.php` ensures the plain index first and removes only the obsolete unique index, retaining foreign keys and records. This completes the older migration's intended one-to-many relationship; it does not implement returning-client selection. Its `down()` intentionally does not restore unsafe uniqueness over historical records.
- **MariaDB fixture corrections:** `AdminAddOnCatalogManagementTest.php` used unsupported status `Pending`; corrected to DRAFT. `CompletePastIntermentsTest.php` used unsupported CANCELLED; tests a supported non-active DRAFT instead, retaining ACTIVE/future/COMPLETED coverage. No status enum was expanded to fit a fixture.
- Additional guards: foreign-branch notification focus exposes no case data; central approval of a payment correction for an activated branch returns 409; branch-local approval preserves the original record, replacement and dirty synchronization state. Correction replacement retry identity is explicitly tested.
- Additional validation fixtures: `IdleSessionTest.php` freezes time for exact-second deadline comparisons (a full MariaDB run crossed a wall-clock second between request and assertion). `tests/Browser/ServiceManagementModalTest.php` waits for the iframe's complete document and actual controls before clicking; optional chaining compared with `!== null` could accept an undefined/loading document. Expected modal navigation remains unchanged.
