# Service Management client brochure/menu

System Admin and Branch Admin can open Print Preview beside the Grid/Table toggle for all/filtered/selected entries in the current catalog tab. An individual item/package has Print Preview in its View drawer header. Packages, Caskets, Hearses, Add-ons, Freebies and Promotions are supported. Print / Save as PDF uses the browser's native print dialog.

The print route is protected by the existing authenticated Admin and branch-scope middleware plus a controller role check. Staff and Owner are denied. It is read-only and does not grant Branch Admin any create, edit, archive, availability or photo-management permission. Branch Admin previews use the assigned branch identity/address. Global Packages, Caskets, Hearses, Freebies, Promotions and unassigned Add-ons remain shared; any branch-specific Add-on is limited to the assigned branch. A Package or Promotion that depends on an Add-on assigned to another branch is excluded from that Branch Admin's printable choices. System Admin retains the global eligible view. The route retains the existing hub search/filter queries; print queries run before pagination. Available packages honor required catalog dependencies. Catalog items must be active/available; only current offers print. Stale or cross-branch selections produce a notice and are excluded. All/selected can include eligible records outside the hub's current pagination/search; filtered mode preserves the applied query. Selection changes must be applied with Update Preview before printing.

A4 portrait menu layout has a white page, logo/business name, configured branch address, prepared date, restrained sage shapes, a botanical line motif, labeled icons and no shadows. Package blocks contain configured services/coverage, the package’s own optional photo, other inclusions and quantities, freebies, excess rates and current promotions. Catalog cards show the applicable specifications and configured price/unit; casket/hearse values are explicitly references rather than invented standalone sale or upgrade charges. Empty sections and internal admin metadata are omitted. Package print photos align with the full width of the package title band and use a 62mm-high cover crop with a slightly raised focal point. Catalog photos use centered 16:9 covers. In a catalog list, each photo fills the card content width. Single catalog previews use a centered cover up to 384px wide. The item title provides the label, and unavailable images leave no empty photo block. Each package starts on a fresh sheet. Long packages continue over pages without truncating rows, and page numbers match the generated preview. No contact values are invented when there is no configuration source.

Implementation: ServiceManagementController::printPreview, Support/ServiceBrochure.php, service-management/print.blade.php, service-brochure.js/css, the new slim Vite entry and shared print action/header links. Printing reads the saved package or catalog photo through the authenticated photo route.
